# DRIVE98

Игровой прототип для начинающих водителей.

Карьера с главами и наградами, карта ночного города, три вопроса ПДД в режиме «Драг», дорожные ситуации «Дрифт», личный маршрут и три поездки в разные дни в режиме «Кольцо», виртуальный гараж и карточки для сторис.

## Запуск

Откройте index.html или опубликуйте корень ветки main через GitHub Pages. Сборка не требуется. Изображения, вопросы и Leaflet включены в index.html.

## Ограничения прототипа

Прогресс сохраняется в localStorage этого браузера. Рейтинг демонстрационный; сервера, регистрации и синхронизации между пользователями нет. Подготовка маршрута требует интернета: OpenStreetMap, Nominatim и OSRM. Импорт полной ссылки Яндекс Карт извлекает точки; путь пересчитывается OSRM и требует подтверждения пользователя. Короткие ссылки не поддерживаются. Потенциально сложные места — подсказки по геометрии маршрута, требующие проверки.

Банк содержит 800 вопросов категории AB из PDD-2026, источник и лицензия приложены. Актуальность каждого вопроса относительно официальных билетов отдельно не подтверждена. Практические задания выполняются без взаимодействия с приложением во время движения.
