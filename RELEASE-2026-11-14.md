# DRIVE98 companion release

Implemented character selection (human, cat, shark), manual appearance controls, single-focus onboarding, acknowledgement, home with four needs, care (petting with synthesized purr, ball interaction, sleep), study tickets and mistakes, simulated computer opponent, and route preparation linked to the existing Yandex import planner.

The existing 800-question bank, original diagrams, authenticated progress, legacy careers and route data remain in place. Companion actions persist through the existing revision-controlled backend. Server function version 34 deployed before the new client. No payment settings or prices changed.

## Deferred capabilities

- AI photo-to-avatar generation needs a configured generation service. The photo tab currently offers local preview only and explicitly states this. Photos are not uploaded.
- Friend matches and separate paid access are not enabled pending tariff and access rules; the screen states this. There is no checkout or invitation link yet.
- Character atlas poses are static frames with CSS motion and interactive ball physics, not fully hand-animated frame sequences. Manual hair and palette controls use compositing over the base sprites.

## Validation

Six pure backend tests pass (existing progress preservation, one focus, time-based sleep, care cooldown, exam result validation, absence preservation). Local mobile UI verified through character setup, focus acknowledgement, home, petting, full 10-question computer match and saved results. Existing Yandex demo URL parsing verified through the new preparation entry. Production Telegram end-to-end validation must be recorded separately.
